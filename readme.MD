# CTTerm

CarlosTraderTerminal is a lightweight,
Python-based command-line trading workstation.

## Features

- Market data via CCXT
- Binance public market quotes
- Rich terminal interface
- Interactive command parser
- Error handling

## Requirements

- Python 3
- CCXT
- Rich

## Installation

```bash
git clone YOUR_REPOSITORY_URL
cd CTTerm

python3 -m venv .venv
source .venv/bin/activate

pip install -r requirements.txt

python main.py# CTTerm
